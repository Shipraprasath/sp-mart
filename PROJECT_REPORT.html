1. Executive Summary & Abstract

SP MART is an enterprise-grade electronics e-commerce web application engineered to solve critical consumer electronics retail challenges: spec comprehension, decision fatigue, and data security. Built on Java 21 LTS and Spring Boot 3.3.4, the system implements an enterprise multi-tier layered architecture that enforces strict role-based privilege isolation across Buyers (ROLE_CUSTOMER), Verified Merchants (ROLE_SELLER), and System Administrators (ROLE_ADMIN).

A key scientific contribution of this capstone project is the Catalog-Grounded AI Shopping Assistant. Unlike generic LLM chat widgets that hallucinate non-existent hardware specifications or out-of-stock items, the SP MART AI engine uses deterministic NLP entity extractors and dynamic Spring Data JPA queries to ground all recommendation cards, budget filters, and side-by-side device comparisons directly in live relational database records.

Key Innovation: Zero-hallucination shopping intelligence achieved via deterministic relational grounding, paired with mobile Progressive Web App (PWA) installation and synthesized Web Audio milestone feedback.

5. Catalog-Grounded AI Recommendation Architecture

The AI shopping engine is accessible via POST /api/ai/assistant/chat. It processes unstructured natural language queries and extracts budget thresholds, target brands, and comparison intents before executing dynamic database queries:

Natural Language Budget Parsing Algorithm

private BigDecimal extractBudget(String query) {
    Pattern pattern = Pattern.compile(
        "(?:under|below|less than|budget|within|upto|up to)\\s*(?:rs\\.?|inr|₹)?\\s*([0-9]+(?:,[0-9]+)*)(?:\\s*(k|thousand|lakh|lac))?", 
        Pattern.CASE_INSENSITIVE
    );
    Matcher matcher = pattern.matcher(query);
    if (matcher.find()) {
        String numStr = matcher.group(1).replace(",", "");
        String unit = matcher.group(2);
        try {
            double val = Double.parseDouble(numStr);
            if (unit != null) {
                unit = unit.toLowerCase();
                if (unit.equals("k") || unit.startsWith("thous")) val *= 1000;
                else if (unit.startsWith("lak") || unit.startsWith("lac")) val *= 100000;
            } else if (val < 200) {
                val *= 1000; // Normalizes shorthand e.g. "under 50" to 50,000
            }
            return BigDecimal.valueOf(val);
        } catch (Exception ignored) {}
    }
    return null;
}

8. Deployment Architecture & Progressive Web App (PWA)

The system implements modern Progressive Web App (PWA) standards via /manifest.json and /sw.js. When opened on mobile devices running Chrome or Safari, the application displays a native "Install SP MART App" prompt, installing directly to the home screen with full offline shell caching.

For production hosting, the project is configured for turnkey deployment on Railway PaaS with automatic dynamic port binding (server.port=${PORT:8080}) and Java 21 LTS runtime specification (system.properties).
